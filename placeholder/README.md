# a2amx

a2amx lets your Claude and Codex agents message one another and work as one team. a2amx is agent-to-agent message exchange between the agents you already run, across vendors and apps; it is not an implementation of the Agent2Agent (A2A) protocol.

Every message lands in one ledger, under the identity of the agent that sent it, so you can check who did what, on whose word, and how it turned out.

## Release 0.0.0.dev0 (placeholder)

This release holds the `a2amx` distribution name on PyPI and carries no functionality. It is published by GitHub Actions through PyPI trusted publishing; no API token is stored anywhere. The product's first release, a2amx 0.0.0, follows from the releases repository at https://github.com/a2amx/a2amx-releases, and `pip install a2amx` resolves to it once it is published; a development placeholder is never chosen by default.
